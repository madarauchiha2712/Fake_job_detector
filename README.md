# Fake_job_detector
Fake Job Detector with ROC

Welcome to the Fake Job Detector project!
In today’s digital world, fake job postings have become a real concern, and this project aims to tackle that problem using machine learning.

What This Project Does

This notebook walks you through building a model that can detect whether a job posting is genuine or fake. We use data preprocessing, classification algorithms, and evaluate our model using ROC (Receiver Operating Characteristic) curves to measure how well it performs.

Key Features

Cleans and Prepares Data: Handles missing values, encodes categories, and normalizes the dataset.

Builds Classification Models: Trains machine learning models to classify job posts as real or fake.

Evaluates with ROC Curves: Uses ROC and AUC scores to assess how well each model performs.

Visual Insights: Includes helpful plots to better understand model performance.


Requirements

Before running the notebook, make sure you have the following Python libraries installed:

pandas

numpy

scikit-learn

matplotlib

seaborn

You can install them with :
pip install pandas numpy scikit-learn matplotlib seaborn

How to Use

1. Clone or download this repository.
2. Open the Jupyter Notebook file fakejobdetector_with_ROC.ipynb.
3. Run the cells step-by-step to explore data, train models, and visualize results.
4. Review the ROC curve to compare


Why It Matters

This project not only demonstrates how machine learning can be applied to real-world problems, but also highlights the importance of evaluating models thoughtfully—especially when it comes to protecting people from scams.
